## 各任务说明

### 任务 1：开机小问题 ✅

- `NAV_VIZ_START_WAIT` 不是整数（比如 `30s`）时，打印原因，按默认 20 s 处理。以前这种情况会在已经启动带桥节点的数据流之后让脚本崩掉。顺带修了 `08` 这类前导零的值。
- 带桥节点的数据流 `dora start` 失败时，先停掉并等到没有正在运行的 `tracer-nav`，再起原数据流；和"起来了但没跑起来"那条路径共用同一段代码。
- 25 个 pytest 通过（测试照旧先把假的 `dora` 放在 PATH 最前面）。审查通过。

### 任务 2：规划器输出代价地图 ⏳

- A* 规划器多一个 `costmap` 输出：
  - 格式是 32 字节小端头（时间戳、宽、高、分辨率、原点）加每格一字节的 Nav2 代价；
  - 0.05 m 一格，不降采样，第 0 行是 y 最小的一行；
  - 有变化时最多每秒一次，另外每 5 s 补发一次。
- `tracer_nav.yml` 声明这个输出；叠加模板接上桥节点的第 11 个输入。
- 不改变规划行为；编码加哈希要在 2 ms 以内。在单独的构建目录里构建和测试，不碰车上用的 `build/`。
