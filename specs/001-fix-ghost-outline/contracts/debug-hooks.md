# 契约：诊断入口（Debug Hooks）

**Feature**: 001-fix-ghost-outline | **Status**: Draft | **Covers**: FR-008、FR-010、R7

本组件已有若干环境变量开关（`URDF_EDGE`、`URDF_AO`、`URDF_SHADOW`、`URDF_PBR_DEBUG` 等）。本契约只新增两个，并规定它们的默认值、副作用与输出格式。

## 1. 新增开关

| 变量 | 取值 | 默认 | 作用 | 副作用 |
| --- | --- | --- | --- | --- |
| `URDF_GHOST_GUARD` | `0` / 未设 | **开启** | `0` 时关闭颜色覆盖门控，恢复修复前行为 | 无；仅影响合成阶段一个分支 |
| `URDF_GHOST_AUDIT` | `1` / 未设 | **关闭** | 设为 `1` 时，在下一个稳定帧读回颜色与深度附件并输出审计结果 | 该帧发生一次设备→主存读回；默认关闭时零开销 |

**约定**

- 两者都只在**进程启动时**读取一次，运行期不再读取（避免每帧 `getenv`）。
- 未设置时的行为必须与修复前**逐像素一致**（除门控本身的效果）：不新增绘制、不新增读回、不新增分配。
- 变量名沿用组件现有 `URDF_` 前缀，便于与既有开关一起被支持人员列举。

## 2. 审计输出

**格式**：单行 JSON，前缀 `URDF_GHOST_AUDIT`，写入标准日志（与组件现有 `RVDBG` 日志同一通道）。

```json
{"URDF_GHOST_AUDIT":1,"frame":120,"pass_size":[2048,1366],"ssaa":2.0,
 "gate":0.25,"candidates":0,"clusters":0,"largest_area":0,
 "verdict":"CLEAN","hypothesis":"UNKNOWN"}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `frame` | u64 | 审计帧号 |
| `pass_size` | [u32;2] | 离屏附件像素尺寸 |
| `ssaa` | f32 | 超采样倍率 |
| `gate` | f32 | 实际使用的覆盖阈值 |
| `candidates` | u32 | 残留候选像素数（`depth < 1-ε ∧ coverage ≤ gate`） |
| `clusters` | u32 | 8 邻域连通簇数量 |
| `largest_area` | u32 | 最大簇面积（像素） |
| `verdict` | string | `CLEAN` 或 `RESIDUE` |
| `hypothesis` | string | `HISTORIC_POSE` / `CURRENT_POSE` / `UNKNOWN` |

**稳定性**：字段只增不改；字段名与大小写视为契约的一部分，供脚本解析（`jq` 按 `.verdict` 判定）。

## 2.1 采集方式（实施修正）

深度附件无法直接读回（渲染框架的读回只支持 8 位颜色目标）。因此审计按两段式采集：

1. **掩码段**：全分辨率，把每个像素的"残留候选"判定结果写入一张 BGRA8 目标（命中记 1，否则 0）。
2. **计数段**：把掩码按块下采样（块内采样后累加），写入一张小尺寸 BGRA8 小目标。
3. **读回**：只读回小目标（KB 级），在 CPU 侧求和并载入 `ResidueAudit`。

代价只在审计帧：两次额外绘制 + 一次小尺寸读回；默认关闭时为零。

## 3. 审计的执行时机

- **只审计"稳定帧"**：相机与关节在一次交互结束后至少静止 1 帧再执行，避免把正在运动中的正常瞬时差异计为残留。
- **每次进程至多 3 次**（首次出现、交互停止后、退出前各一次），防止日志淹没。
- 审计本身不得改变渲染结果：读回是只读操作，不复用为纹理、不改清除值。

## 4. 与非目标的关系

- 本契约**不**承诺在 CI 中运行审计：CI 是 Linux 无窗口环境，缺少 GPU 上下文。审计只用于开发机与验收机。
- 审计不替代人工观感验收，只提供"是否存在残留"的客观下限。

## 5. 移除条件

当上游 `dorobot-org/makepad-urdf-viewer` 接受等价修复，且本仓库同步到含该修复的版本后，`URDF_GHOST_AUDIT` 可移除；`URDF_GHOST_GUARD` 应在同一版本移除（届时不再需要并排比较）。
