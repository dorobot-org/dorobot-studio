# 契约：视觉不变量（Visual Invariant）

**Feature**: 001-fix-ghost-outline | **Status**: Draft | **Covers**: FR-005、FR-007、FR-010、SC-001

本契约把规格中的"空白背景不得出现残留轮廓"写成一条可判定的像素级规则。它是本次修复的**验收基准**，也是后续任何改动该合成通道的人必须保持的约束。

## 1. 不变量

对每个被合成到屏幕的像素 `p`：

```text
若 coverage(p) ≤ gate_threshold ：
    可见颜色(p) = 背景(p)                    // 不得施加描边、凹陷或任何压暗
否则 ：
    可见颜色(p) = 背景(p)·shade(p) + 场景颜色(p)   // 与修复前公式一致
```

其中：

- `coverage(p)` = 该像素采样到的场景颜色 alpha（已含超采样平均）
- `gate_threshold` = `1 / ssaa_scale²`（超采样 2× 时为 **0.25**）
- `shade(p)` = 修复前的描边/凹陷项（公式与阈值**不得改动**）

**推论（可计数形式）**：

```text
residue(p) ⇔ depth(p) < 1-ε ∧ coverage(p) ≤ gate_threshold
SC-001 要求：Σ residue(p) = 0
```

## 2. 为什么这是正确的约束（而不是"藏起来"）

- 描边的语义是"表面之间的交界"。没有表面（没有颜色覆盖）的地方不存在交界，因此**不允许**被描边。门控表达的是语义本身，不是对某个具体 bug 的特判。
- 该约束不依赖"深度为何会残留"：无论是附件跨帧累积、同帧二次深度写入，还是未来新增的深度专用通道，只要没有颜色覆盖，就不会产生可见痕迹。
- 它与 `URDF_EDGE` / `URDF_AO` 开关正交：关闭效果时无描边可残留；开启效果时门控生效（FR-010）。

## 3. 必须保持的行为（防退化）

| 必须保持 | 判定 |
| --- | --- |
| 真实 silhouette 的描边存在且位置不变 | 与基线截图差分 ≤ 2%（SC-004） |
| 接触处的凹陷阴影存在 | 同上 |
| 超采样边缘不被吃掉 | 边缘带像素覆盖 ≥ 0.25（真实边缘约 0.5，留有余量） |
| 门控不改变深度写入或几何绘制次数 | 深度/绘制调用计数与修复前一致 |

## 4. 验收

1. **自动**：开启 `URDF_GHOST_AUDIT=1`，在"移动视角/关节后静止"的帧上执行审计，`ResidueAudit.verdict` 必须为 `CLEAN`（`candidates = 0`）。
2. **回归**：`cargo test --locked --workspace --no-default-features` 全绿（含新增审计纯逻辑单测）。
3. **观感**：5 个界面的基线截图对比通过（`quickstart.md` §4）。
4. **鲁棒**：`URDF_EDGE=0`、`URDF_AO=0`、`URDF_GHOST_GUARD=0` 三种组合下，审计结果各自符合预期（见 `debug-hooks.md`）。

## 5. 违约处理

- 若 `residue > 0` 且簇与历史姿态一致（`HISTORIC_POSE`）：说明门控未生效或深度残留绕过了门控，属实现缺陷，回到 `render-lifecycle.md` 排查。
- 若 `residue > 0` 且簇与当前姿态重合（`CURRENT_POSE`）：说明同帧存在"只写深度"的绘制，属实现缺陷。
- 若基线差分 > 2%：先判断差异是否落在边缘带；落在边缘带外即视为描边退化（FR-007 违约），必须调整阈值或公式，不得用"看起来还行"放行。
